My Projects

Stock Portfolio Management System

The Stock Portfolio Management System is a full-stack web application developed using the MERN Stack. The application enables users to manage their stock investments through an interactive dashboard where they can add, edit, update, and remove stock information. Users can organize their investments, monitor their portfolio, and view important financial details in a clean and responsive interface.

Face Recognition Attendance System

This project is an intelligent attendance management system that uses facial recognition technology to automate student attendance. The application captures images using a webcam, recognizes registered students, and automatically marks attendance without manual intervention. It reduces errors, saves time, and improves the efficiency of attendance management.

Book Swap Website (Flipy)

Flipy is a responsive web application that allows users to exchange books with one another through an easy-to-use platform. Users can register, upload books, browse available books, and send swap requests. The objective of this project is to encourage book sharing and make reading resources more accessible while reducing unnecessary purchases.
