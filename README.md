💻 Getting Started

To get a copy of this repository on your local computer, clone the repository using Git.

git clone https://github.com/Prashant4050/Summer-Intership.git

Move into the project folder:

cd Summer-Intership

Each project is located in a separate directory.

▶️ Running HTML, CSS and JavaScript Projects

For projects built with HTML, CSS, and JavaScript, open the project folder and run the index.html file in your web browser.

For example:

E-commerce/
│
├── index.html
├── style.css
└── script.js

You can also use the Live Server extension in Visual Studio Code.

⚛️ Running React Projects

For React projects, move to the project directory:

cd weather-dashboard

Install the required dependencies:

npm install

Start the development server:

npm start

The application will usually open in your browser at:

http://localhost:3000
🖥️ Running Backend Projects

For backend projects using Node.js and Express, move into the backend directory:

cd backend

Install the dependencies:

npm install

Then start the server using the appropriate command configured in the project.
